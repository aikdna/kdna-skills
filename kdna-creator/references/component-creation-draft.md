# Typed authoring through current Studio

A judgment group has an ASCII local key and at least two substantive alternatives. Local keys match `^[a-z][a-z0-9-]{0,63}$`; they are authoring references, not protocol IDs. Studio deterministically materializes owner-qualified IDs under `kdna.studio-materialization/2` and binds the full asset/version/context before Compiler. Do not generate native IDs or digests in the Agent adapter.

An alternative provides title, subject, scope, statement, rationale and explicit material references. Optional method is `{method:{term},components?,bindings?}`. A component provides localKey, one of taxonomy/candidate-set/discriminator-set, content and optional authored statement. Items provide key/title/meaning. Taxonomy also provides broader edges; discriminator-set provides candidateSetLocalKey and discriminators containing key/title/prompt/contrasts. A contrast refers to a candidate key and its criterion. Bindings are local component key plus role, always targeting the owning judgment. The exact finite grammar and limits belong to Core, not this prose adapter.

Only select a built-in method when supported by the actual content. Missing method remains absent. Missing components/bindings are undeclared, while explicit arrays are declared, including empty arrays. Unknown/null/extra fields do not become meaningful through defaults. Candidate-specific applicability stays in its own meaning or criterion. `formationRule:{conditions:[{kind:'interpreted',statement}]}` explicitly expresses an overall formation rule; `conditions:[]` remains empty and creates no fixed result. Absence of formationRule authors an ordinary text result.

Public source records declare localKey, public identity, optional version/digest and explicit uses. Uses name localKey, public source role and optionally a componentLocalKey. Notices declare localKey, public statement and sourceLocalKeys. Preserve real licensing and provenance; publish only explicitly designated source identities/notices, never private paths or whole authoring transcripts automatically.

Record alternatives, actual selection, revisions and reasons in the live session. Review the complete current mapping, then obtain a fresh role-specific final adoption. The private evidence records content and actual replies, but is not a credential. Use export/save/readback completion and keep external bindings. Do not re-sign a changed asset, relabel old evidence, restore a one-use context, or claim static consistency proves execution authenticity.
